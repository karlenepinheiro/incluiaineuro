3Gabarito — rastreamento ponta a ponta

  1. Seleção do modo → texto livre do professor (sem campo estruturado de "tipo" no modo legado).
  2. topicRequestsAvaliacao(topic) reaproveita AVALIACAO_KEYWORDS já exportado de intentExtractor.ts — sem duplicar a lista.
  3. Quando true, buildPremiumActivityPrompt adiciona ao contrato JSON um campo "gabarito" array, com instrução de obrigatoriedade.
  4. generateA4Economica faz JSON.parse best-effort do resultado e extrai legacyAnswerKey — sem fabricar nada se ausente/malformado (ao contrário do bug antigo do Guia).
  5. hasGabarito passa a reconhecer tanto activityPackage.answerKey (canônico) quanto legacyAnswerKey (legado).
  6. Novo componente LegacyAnswerKeyView renderiza o gabarito legado (não reaproveita AnswerKeyRenderer porque este exige ActivitySchema.exercises com id estável — o contrato legado só tem number).

4Exportação PDF/PNG — nova arquitetura

Causa suspeita (não 100% confirmável sem debug ao vivo): o preview compacto introduzido na Etapa 4D envolveu o elemento exportado num wrapper overflow:hidden + maxHeight — reintroduzindo o tipo de instabilidade estrutural (ancestral com clipping) já suspeito na causa original.

Correção estrutural (não outro ajuste de timing): três refs de exportação dedicados (exportFolhaRef/exportGuiaRef/exportGabaritoRef), sempre montados num container position:fixed; left:-10000px — nunca display:none (que o html2canvas não consegue capturar), nunca dentro do card compacto nem do modal. O mesmo result alimenta as duas cópias via as funções compartilhadas renderFolhaStage/renderGuiaStage/renderGabaritoStage — nenhum conteúdo pedagógico duplicado ou divergente.

5A4 Visual — decisão de arquitetura

Confirmado por auditoria de prompt: o fluxo atual pede à Vertex Imagen para desenhar a folha inteira com texto de questões. Isso é uma limitação estrutural do modelo de imagem, não um problema de redação de prompt.

Implementado nesta etapa: redução de "3 a 5 questões" para "2 a 3 questões curtas", instrução explícita anti-erro-de-ortografia, e o mesmo bloco de qualidade pedagógica da A4 Econômica adicionado ao prompt de texto-fonte (buildGuiaEConteudoPrompt).

Não implementado nesta etapa (delta documentado, não "gambiarra"): a conversão completa para Gemini JSON → ActivityA4Premium (renderer) → Imagen só para ilustração pequena, que exigiria mudar qual conteúdo é primário na aba "Folha do Aluno" para os 4 modos Visual/Premium/Adaptar-Visual/Adaptar-Premium — risco real de regressão sem ambiente de teste visual disponível. Recomenda-se um "Sprint Visual" dedicado, com acesso a teste real, para essa mudança maior.

6Custos — sem alteração

Nenhuma chamada de IA nova foi adicionada; nenhuma chamada existente foi removida. As mudanças desta etapa são: (a) parsing client-side adicional do JSON já retornado (gabarito, tipo original) — sem custo de IA; (b) texto de prompt mais rico — mesmo número de chamadas, sem afetar creditsRequired. _credits.ts e RPCs não tocados.
