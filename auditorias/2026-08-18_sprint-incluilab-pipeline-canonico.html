Sprint IncluiLAB - Pipeline canonico

Data: 2026-08-18

Escopo: migracao controlada de A4 Economica, Avaliacao e Adaptar Texto para o pipeline canonico existente, mantendo Visual/Premium no legado.

Resultado

  • A4 Economica, Avaliacao e Adaptar Texto roteados por flags segmentadas.
  • Pipeline canonico ampliado para preservar estruturas como caca-palavras, cruzadinha, colorir e tabela.
  • Avaliacao passou a usar requestType explicito, folha do aluno e gabarito.
  • Adaptacao textual passou a enviar tipo original detectado e a validar preservacao estrutural.
  • Renderer A4 canonico passou a renderizar os novos tipos estruturais sem truncar no caminho canonico.

Limites respeitados

  • Nenhuma migration, SQL, Supabase rule ou schema de banco foi alterado por esta sprint.
  • Nenhum arquivo do AI Gateway foi editado por esta sprint.
  • Nenhuma integracao OpenAI/Gateway foi implementada nesta sprint.
  • Autosave, Biblioteca, preview e exportacao existentes foram preservados.

Rollback

Para desativar a migracao textual, alterar src/config/incluilabPipeline.ts e definir como false os modos a4_economica, avaliacao e adaptar_economico em INCLUILAB_CANONICAL_PIPELINE_BY_MODE.

Validacao

  • npm test -- --reporter=dot: 13 arquivos, 124 testes aprovados.
  • npm run build: build concluido com sucesso; somente avisos existentes de chunks/dynamic import.

Observacao

A arvore de trabalho ja continha alteracoes paralelas e arquivos nao rastreados antes/fora desta sprint, incluindo areas de Gateway e UI. Eles foram tratados como fora de escopo e nao foram revertidos.
